# Layers (Design + State)

This system is structured into four layers. States are enforced by governance.

| Layer | Description | State |
| --- | --- | --- |
| 1 | Human interface (calm chat front door) | ACTIVE |
| 2 | Control & governance layer (planner, governor, audit) | ACTIVE |
| 3 | Operator console (advanced command center) | ACTIVE |
| 4 | External interaction (email/calls/network) | LOCKED |
| 5 | Autonomous expansion / agent spawning | DISABLED |

External interaction remains locked by policy. Autonomous expansion remains disabled.
